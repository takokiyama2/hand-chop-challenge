# 団長の手刀を見逃さないチャレンジ

**倒れた。その直前に、何があった？**

複数の監視モニターから、一瞬の手刀を見つける観察・反応ゲームです。

人が倒れたからといって、手刀を受けたとは限りません。ヒールが折れたのかもしれないし、足を滑らせただけかもしれない。

見抜くべきは、相手が崩れ落ちる直前、首元を通ったその手。

目指せ、最高の観察者。


## 遊び方

初回はチュートリアルで、本編と同じ人物シルエットを使って団長と占い師を見分ける練習をし、手刀の短い実演映像を見られます。操作とルールも説明します。スキップでき、ヘッダーの「遊び方」からいつでも見返せます。

1. 映像中央のマークをタップして、監視開始。
2. **団長の手刀を見つけたら、手刀が映ったモニター全体を素早くタップ！** 
3. 選んだ映像だけを直前2秒まで巻き戻し、自動判定。
4. その2秒間に手刀が映っていれば成功。「次のステージへ」で次の面に挑戦します。

別の画面を止めたり、ただの仕草や転倒を手刀と勘違いしたり、手刀を2秒以上見逃したりするとゲームオーバー。「この面をやり直す」か「最初からやり直す」を選べます。


## 全10面。最後の一瞬、見えるか？

ラウンジ、連絡通路、ギャラリー、屋上テラスなど、監視する場所はさまざま。
別の部屋でもほぼ同時に人が倒れたり、挨拶や腕回しに目を奪われたり。視線を配り、手の動きと転倒のつながりを見抜いてください。
