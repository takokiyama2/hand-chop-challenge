# 団長の手刀を見逃さないチャレンジ

**倒れた。その直前に、何があった？**

複数の監視モニターから、一瞬の手刀を見つける観察・反応ゲームです。

人が倒れたからといって、手刀を受けたとは限りません。ヒールが折れたのかもしれないし、足を滑らせただけかもしれない。

見抜くべきは、相手が崩れ落ちる直前、首元を通ったその手。

目指せ、最高の観察者。

## 遊び方

初回はチュートリアルで、本編と同じ人物シルエットを使って団長と占い師を見分ける練習をし、手刀の短い実演映像を見られます。操作とルールも説明します。スキップでき、ヘッダーの「遊び方」からいつでも見返せます。

1. 映像中央のマークをタップして、監視開始。
2. **団長の手刀を見つけたら、手刀が映ったモニター全体を素早くタップ！** 倒れた人を直接タップする必要はありません。
3. 選んだ映像だけを直前2秒まで巻き戻し、自動判定。
4. その2秒間に手刀が映っていれば成功。「次のステージへ」で次の面に挑戦します。

別の画面を止めたり、ただの仕草や転倒を手刀と勘違いしたり、手刀を2秒以上見逃したりするとゲームオーバー。「この面をやり直す」か「最初からやり直す」を選べます。「最初からやり直す」を押すと、そこまでの合計スコアに応じた総合レベルが表示されます。

成功時は自分が止めた映像だけを再生します。失敗時は「正解映像」へ切り替えて、本物の手刀の前後を確認できます。通常・スロー・超スロー再生やコマ送りにも対応しています。

## スコアと総合レベル

正解で100点。反応ボーナスは0.30秒以内で50点、2.00秒で0点。早いほど高くなるよう、区間ごとに重みを付けて加点します。2回目以降の連続成功で各20点。1面からミスなく続けてクリアすると、6面+10点、7面+20点、8面+50点、9面+90点、10面+150点の連続クリアボーナスが加わります。ミスは50点減点され、連続数とボーナスの流れもリセット。全10面をノーミスかつ0.30秒以内でクリアしたときの最高点は2,000点です。挑戦を終えると、その時点の合計スコアに応じた総合レベルが表示されます。どのレベルになるかは、ぜひプレイして確かめてください。

反応ボーナスの目安：0.30秒以内は50点、0.301～0.333秒は49～45点、0.334～0.366秒は44～39点、0.367～0.400秒は38～33点、0.401～0.444秒は32～27点、0.445～0.750秒は26～15点、0.751～1.111秒は14～7点、1.112～1.999秒は6～1点。

## 全10面。最後の一瞬、見えるか？

ラウンジ、連絡通路、ギャラリー、屋上テラスなど、監視する場所はさまざま。

| ステージ | モニター数 | 手刀の長さ |
| --- | ---: | ---: |
| 1 | 1画面 | 20フレーム（約0.33秒） |
| 5 | 4画面 | 8フレーム（約0.13秒） |
| 10 | 9画面 | **2フレーム（約0.033秒）** |

後半は、別の部屋でもほぼ同時に人が倒れたり、挨拶や腕回しに目を奪われたり。視線を配り、手の動きと転倒のつながりを見抜いてください。

※ フレーム数は60fps基準の手刀の長さです。実際の見え方は端末やブラウザの描画性能によって変わります。

## 見逃さなかった、その先に

成功時のお決まりの台詞は、

> おそろしく速い手刀　オレでなきゃ見逃しちゃうね

挑戦を終えると総合レベルが表示されます。全10面をクリアした場合は、認定証も保存できます。
